# Contributing to StrPP
These types of contributions are allowed for StrPP:
- Bug fixes
- Performance fixes
- Features (most recent release only)

Things you should keep in mind when contributing:
- You should always follow the style and flow of the original code, make sure your code fits in.
- StrPP uses Semantic Versioning, so keep that in mind.
- Your commit messages must follow Conventional Commits and accurately describe your changes/additions.

Not required, but preferred:
- Tabs should use actual tab characters rather than spaces. You should hopefully be able to configure your IDE to do this.

Contributions that are for versions older than the last MAJOR release will be rejected.
Contributions that add features to any release older than the current release will be rejected.
Contributions that fix bugs for the most recent release, or the previous MAJOR release will be approved provided they follow the guidelines specified above.
See SECURITY.md for more details.
