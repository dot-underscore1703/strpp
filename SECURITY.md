# StrPP Security Policy
## StrPP Support Policy
StrPP development support is for the most recent release and the previous MAJOR version.
E.g: if StrPP is on version 5.0.0, versions 5.0.0 and 4.0.0 will be supported, but any versions older are to be considered to be in End-Of-Life and will be unsupported.

If you are using an EOL release, it is recommended you upgrade to a supported release for the latest features and bug fixes.

Only the most recent release will receive new features, the previous release is only still supported purely for bug fixes.
